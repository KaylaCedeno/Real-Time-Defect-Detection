# Real-Time-Defect-Detection

A real‑time quality‑inspection tool that uses a laptop webcam to detect surface defects (scratches, dents, cracks) on handheld manufactured parts. The system combines classical computer vision with a lightweight deep learning model to classify objects as “good” or “defective” and highlight anomalies using bounding boxes and heatmaps. Built with Python, OpenCV, and PyTorch, the pipeline runs at 15–30 FPS and is robust to variations in lighting, angle, and motion.

This project is to deepen my practical skills in computer vision and real‑time perception. With this project I hope to demonstrate that I can design end‑to‑end perception systems — not just train models, but build something that behaves like a real product.
